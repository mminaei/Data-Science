# Data-Science

Data science and machine learning projects related to oil and gas well data.

## Colorado

Codes we used at our startup, NeuDax. In ML_test_001 we predict the depth of the Niobrara formation using a very limited amount of data.

## DCA_Analysis_UAT

A program to do Decline Curve Analysis on well production data. It is not machine learning, but it is related to what we do with well data.
